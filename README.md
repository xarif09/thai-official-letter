# ระบบจัดหน้าหนังสือราชการ

กรอกข้อมูลลงฟอร์ม แล้วระบบจัดวางหนังสือราชการให้ตามรูปแบบงานสารบรรณ ดาวน์โหลดเป็นไฟล์ Word (.docx) หรือพิมพ์ / บันทึกเป็น PDF ได้ทันที

**ทดลองใช้:** https://zoomyyala.github.io/thai-official-letter/

ทำงานในเบราว์เซอร์ทั้งหมด ไม่ส่งข้อมูลออกไปที่ไหน ข้อมูลที่กรอกเก็บไว้ในเบราว์เซอร์ของเครื่องที่ใช้เท่านั้น

## รองรับ
- หนังสือภายนอก
- บันทึกข้อความ (หนังสือภายใน)
- หนังสือประทับตรา
- คำสั่ง / ประกาศ

## แสดงผล 2 แบบ
- **ฉบับจริง (ส่งออก)** — มีตราครุฑ
- **สำเนาคู่ฉบับ (เก็บที่ต้นเรื่อง)** — ไม่มีครุฑ พิมพ์คำว่า "สำเนาคู่ฉบับ" ตัวหนา 32 pt กึ่งกลางด้านบนแทน และมีช่อง ร่าง / พิมพ์ / ตรวจ ไว้ลงลายมือชื่อย่อที่ข้างท้ายขอบล่างด้านขวา (ระเบียบงานสารบรรณ ข้อ 30) ส่วนเนื้อหาอื่นเหมือนฉบับจริงทุกประการ
- ปุ่ม "Word ทั้ง 2 ฉบับ" ดาวน์โหลดทั้งสองแบบพร้อมกัน (บันทึกข้อความไม่มีสำเนาคู่ฉบับ)

## สิ่งที่ระบบจัดให้อัตโนมัติ
- ครุฑกึ่งกลางกระดาษ (3 ซม. / บันทึกข้อความ 1.5 ซม. มุมบนซ้าย) ขอบซ้าย 3 ซม. ขอบขวา 2 ซม.
- ชื่อหน่วยงานและที่อยู่: บรรทัดยาวสุดชนขอบขวา ตัดบรรทัดให้เองถ้ายาวเกิน
- วันที่และคำลงท้ายเริ่มตรงกึ่งกลางครุฑ · ชื่อ/ตำแหน่งผู้ลงนามกึ่งกลางใต้คำลงท้าย
- อ้างถึง / สิ่งที่ส่งมาด้วย: กดเพิ่มทีละรายการ ใส่เลข ๑. ๒. ให้เอง · "จำนวน ... ชุด" ชิดขวาบรรทัดเดียวกับชื่อเอกสาร
- ข้อความกระจายแบบไทยชิดขอบซ้าย-ขวา · ย่อหน้า 2.5 ซม. · ระยะ 1 Enter + 6 pt / คำลงท้าย 12 pt
- ย่อหน้าสุดท้าย คำลงท้าย และลายมือชื่อไม่แยกหน้ากัน · หน้า 2 เป็นต้นไปมีเลขหน้า "- ๒ -"
- QR Code สิ่งที่ส่งมาด้วย วางข้างลายมือชื่อ · ตัวหนา `**ข้อความ**` ขีดเส้นใต้ `__ข้อความ__`
- เลขไทย · เว้นเลขวันที่ไว้กรอกตอนลงนาม · สำเนาคู่ฉบับ (แทนครุฑ) · ชั้นความเร็วสีแดง

## ข้อแนะนำ
- เครื่องที่ใช้ต้องมีฟอนต์ TH SarabunIT๙ (หรือ TH SarabunPSK / TH Sarabun New)
- ตอนสั่งพิมพ์ PDF: ขนาด 100% · ระยะขอบ "ค่าเริ่มต้น" · ปิด "ส่วนหัวและส่วนท้าย"
- ถ้าเนื้อหาเกิน 1 หน้า ให้พิมพ์คำต่อเนื่อง "คำ.../" มุมขวาล่างเองใน Word
